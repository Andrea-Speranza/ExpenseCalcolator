# adapters/remote-gdrive — RemoteStore su Google Drive API

Operazioni `list` / `read` / `create` su una cartella condivisa di Google Drive, con login OAuth (PKCE) e
gestione dei limiti di frequenza.

Prima di implementarlo serve l'esito dello spike S1 (scope `drive.file` contro `drive`).

- **Stato:** da implementare, Fase 6.

Dettagli: [PLANNING §8.8](../../../docs/PLANNING.md#88-note-su-google-drive-da-verificare-nello-spike-s1).
