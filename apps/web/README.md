# apps/web — Shell PWA

Pubblica la build di `packages/ui` come Progressive Web App:

- manifest dell'app installabile;
- Service Worker che mette in cache tutta l'app per il funzionamento offline;
- collegamento degli adapter web all'engine (IndexedDB, Google Drive, File System Access dove disponibile);
- deploy statico, senza backend (D7: GitHub Pages o Cloudflare Pages).

- **Stato:** da implementare, Fase 3.
